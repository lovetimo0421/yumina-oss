# Advanced Guide

Creators have built worlds with in-game phone chat groups between NPCs, WASD-controlled exploration with interactive maps, point-and-click adventure games, civilization-style strategy games run by the AI, visual novels with branching timelines, and survival simulations with crafting and combat. A card's interface code runs in a sandbox that supports ordinary web technology (with limits, see [3D, Panoramas & Binary Assets](/creator/advanced/3d-and-assets)), and the Creation assistant can write that code for you.

The pages in this section explain how those worlds are put together. They assume you've read [Canvas basics](/creator/canvas).
